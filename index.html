Bitlings

macOS build · not distributed

A pixel desktop pet that quietly measures how you use the web, then writes you an honest report about it every morning at nine.

Version1.7.0
Watched sites50
RuntimeElectron
ArtRaster canvas

A transparent, click‑through Electron window drops a hand‑drawn pixel creature onto your desktop — draggable, click‑through on empty pixels, position remembered across restarts. Underneath it is a pet‑care loop, a berry‑catching minigame, a shop, four companions and a four‑chapter story. A paired Chrome extension measures foreground time on one approved site at a time.

The design constraint I care about most: it never makes anything up. The extension reads focus and visibility, not page content — no URLs, no titles, no account data. Overlapping tabs get merged so time can't inflate. An optional local Ollama model picks from authored lines under constrained JSON, so it can flavor a report but can't change a number. No observations is labeled "missing evidence," not "zero usage."

Signed macOS build — I can send the .app or demo it live
